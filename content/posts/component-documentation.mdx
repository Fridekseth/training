The field of learning is big, and not possible to cover in just a few months work. An important aspect of this project has therefore been to document all work, so that it can be taken further by someone else in the future. OpenBridge for learning is also in the works as a possible future research project in the lab, so I wanted my work to be a good foundation for future projects on the topic.

I chose to document everything on this website as I went, so that everything would be easily available. The most important part of this documentation is perhaps the new component documentation, that documents my learning concept as it stands today.

The documentation is separated into three categories:

## [Visual language](/documentation/visual-language)

These are the foundations, such as colors, illustrations, icons and styles, that make up the «language» of OpenBridge learning. It has the important task of separating learning from the main interface. It can be seen as a pedagogical layer, separate from the main OpenBridge identity, while at the same time appearing in the same family.

## [Components](/documentation/components)

Components for learning are interactive building blocks that are made specifically to support the OpenBridge learning patterns. They are either customized versions of existing OpenBridge UI components, or new components that follow the OpenBridge guidelines.

## [Patterns](/documentation/patterns)

Learning patterns describe how visual elements and components can be used in order to achieve effective learning in the interfaces. They show the essential patterns for layout and interaction, and are made to fit different learning scenarios.
