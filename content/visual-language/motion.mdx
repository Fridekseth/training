## What

Learning specific motion can be used to emphasize to the user that they start a new "mode", whether that be a test, a run-through or another learning pattern.

## How to use

Motion in learning should be used to mark big changes in the interface. I have mainly done experiments with animation so far, and have not had time to consider specific animation guidelines for learning yet.

OpenBridge has motion guidelines for UI.
