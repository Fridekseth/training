## Why

OpenBridge has an extensive color library, and new application layers, like Learning, AI, Advice and so on, need to take this into consideration when working with color as a visual mark. To ensure safety, the contrast between new «layer-colors» and the existing library needs to be sufficient, especially when put up against critical alarm colors.

Learning uses the base color teal, because it is already integrated in the palette and defined with contrast in mind. It is also one of the base colors that sits farthest away from critical alarm colors, making it one of the safer options. ## How to use

The teal accent color should be used sparingly, mainly to make a clear distinction between the main interface and the learning content.
