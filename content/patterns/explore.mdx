## What

In explore mode the learner can click around in the interface without controlling the system. It is a safe place to practice without fear of making mistakes. It is only available when the system is not in use.

## How it works

1. The learner starts explore mode from the Explore page.
2. The screen is framed in teal, so it is clear that it is not the live system. The cursor changes to a hand.
3. Everything can be pressed without any effect on the system.
4. The [mode tab](/documentation/components/mode-tab) in the corner allows the user to quit the mode.

## Why

The research shows that crew are often afraid to make mistakes when first introduced to new technology. In the case of Wavefoil, a big part of introducing the foils is to make them feel safe.

Similar "sandbox" types of learning can be found in services like <SourcePill href="/research#stripe-sandbox">Stripe</SourcePill>. The teal frame shows the user that they are in a different mode is inspired by the green dev mode in <SourcePill href="/research#figma-onboarding">Figma</SourcePill>.
