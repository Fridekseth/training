## Overview

The mode tab sits in a corner of the screen for as long as a training mode is open. It names the mode, and when the mode is about something, such as a chapter or a scenario, it names that too. Pressing it opens the mode's menu, and a handle on it moves it to another corner.

It is the same component in every mode. Only the icon and the words change.

## Behaviour

1. When a mode opens, the [mode intro](/documentation/components/mode-intro) is shown in the middle of the screen and then settles into the tab, so the tab is already in place when it arrives.
2. The tab keeps its words for four seconds, and then folds to the icon and the handle.
3. A pointer over the icon unfolds it again. The handle does not unfold it, so the handle can always be grabbed without the tab moving. A finger has no hover, so touch does not unfold it.
4. Pressing the tab opens the mode's menu, and pressing it again closes it.
5. Dragging the handle moves the tab. When it is let go it snaps to the nearest corner.

## Accessibility

- The tab is a button that reports whether the menu is open, and is called "Training menu" for a screen reader.
- Without a pointer, the arrow keys on the handle step the tab between the corners.
- Unfolding on hover is left out for touch, where it would unfold on every press.

## Theory

The tab, together with the teal frame, is there so the learner always knows they are in training and not in the live system. [The theory post](/blog/connecting-prototype-to-learning-theory) points at Figma's dev mode as an example of showing the user that they are in a different mode: <SourcePill href="/research#figma-onboarding">Figma</SourcePill>.

At the [OpenBridge seminar](/blog/openbridge-seminar-feedback), a participant compared it to their own training mode, which is only a red bar along the top, and found it easier to tell which mode they were in.

## Implementation

Built from custom parts, not from an OpenBridge component: a button, a mask icon and the handle in `CornerTools`, which also holds the dragging and the snapping to corners.
