## Overview

The mode tab sits in a corner of the screen for as long as a training mode is open. It names the mode you're in, and any relevant info, like for example the current chapter or scenario. It can be dragged between the different corners by the user, if it covers parts of the screen you wish to see.

## Features

- Names the mode with an icon and a bold label, followed by what it is about.
- Keeps the text for four seconds after it has docked, and then folds to only show the icon and handle.
- Unfolds again on hover.
- Opens the mode's menu when it is pressed, and closes it when it is pressed again.
- Moves to another corner by its handle, and snaps to the nearest one when it is let go. The arrow keys on the handle do the same without a pointer.
