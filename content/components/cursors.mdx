## Overview

The different cursors say what the pointer does. They are drawn in the teal of the learning layer, so the mode can be recognised in the pointer itself, and not only on the screen.

## Features

- Shows a teal pointer for the regular pointer
- Shows a hand when the user is only looking around, not controlling the system.
- Shows a comment cursor when the tool Comments is on, where a click puts down a comment.
- Falls back to the system's own cursor if a picture does not load: the standard pointer, a grabbing hand or a cross.

## Variants

- Pointer
- Hand
- Comment
