## Overview

The thread is a panel that opens at the side of the screen when a [comment pin](/documentation/components/comment-pin) is pressed. It holds the conversation, and a field to write an answer in. The message and text area field is based on existing OpenBridge components.

## Features

- Has a header with a comment icon, title and close button.
- Message area, with all sent messages. The area scrolls if messages do not fit.
- Shows the learner's own messages on the right, with filled initials, and everyone else's on the left, with outlined ones.
- Has a text area field at the bottom. Pressing the field opens the on-screen keyboard, so the system keyboard never covers the screen.
- Stands on the left or the right of the screen, and can start below the top bar.

## Variants

- **Side.** On the left or the right of the screen.
