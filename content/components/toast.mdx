## Overview

The toast in learning is a version of the original OpenBridge toast, that tells the user what to do when in a scenario where there is limited space to give instructions. It has a drag icon, so that it can be moved freely on the screen.

## Features

- Names the task in bold, with a second line under it when there is more to say.
- Has a cancel button with a ring round it. The ring turns while the sequence starts, and runs down while the time to do the task goes.
- Has a handle, to move the bar when needed. The arrow keys move it too.
- Stays inside the screen when it is moved.

## Variants

- Title only, or title and subtitle.
