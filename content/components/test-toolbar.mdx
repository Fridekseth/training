## Overview

The test toolbar is the toolbar allowing users to see their progression in a test and navigate between tasks. It is based on the OpenBridge sequence toolbar, but with the added drag icon, allowing it to be moved on the screen.

## Features

- Has Previous on the left, a step for each question, and Next on the right.
- Marks the steps: completed for the questions before the one being answered, active for that one, and not started for those after it.
- Navigates to a question when its step is pressed.

## Variants

- **On the question page.** Along the bottom of the screen, where it stays.
- **Over a scenario.** Floats over the screen while a task is carried out, with a handle to move it if necessary. The arrow keys move it too.
