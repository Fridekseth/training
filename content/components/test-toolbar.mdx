## Overview

The test toolbar is the toolbar along the bottom of a test. It has a step for each question, and it moves between them.

## Features

- Has Previous on the left, a step for each question, and Next on the right.
- Marks the steps: completed for the questions before the one being answered, active for that one, and not started for those after it.
- Goes to a question when its step is pressed.
- Says Back instead of Previous on the first question, which leads to the page that introduces the test.
- Says Finish instead of Next on the last question.
- Grows when there are more questions than fit.

## Variants

- **On the question page.** Along the bottom of the screen, where it stays.
- **Over a scenario.** Floats over the screen while a task is carried out, with a handle to move it off whatever it covers. The arrow keys move it too. A button in the corner takes the screen back to the question without finishing the scenario.
